# AURIS — Project Showcase Website

A ready-to-publish, responsive, static website for your SAIF 2026 poster QR code.

## Preview on your Mac

Open `index.html` in Safari or Chrome. No installation, backend, database, or internet connection is required for the content (the optional Google Fonts use the internet; system fonts are the fallback).

## Publish free using GitHub Pages

1. Create a new **public** GitHub repository, e.g. `auris-showcase`.
2. Upload the **contents** of this folder (index.html, styles.css, assets/, documents/) to the repository root. Do not upload just the ZIP.
3. In the repository, open **Settings → Pages**.
4. Select **Deploy from a branch**, branch **main**, folder **/(root)**, and save.
5. Wait for deployment. The URL will typically be `https://YOUR_USERNAME.github.io/auris-showcase/`.
6. Open the live site on your phone, test all links, and generate your poster QR code from the **actual published URL**.

Alternatively, drag this unzipped folder into Netlify Drop for static hosting.

## Add your demo video

The demo section currently says "Demo video coming soon"; no fake video link is provided. When your video is ready, replace that section in `index.html` with a link or embed to your video (e.g. YouTube or a video file you have permission to publish).

## Included original materials

- Full AURIS technical report (PDF)
- Editable SAIF project poster (PPTX)
- Extracted system architecture, hybrid sound-detection, prototype, and optical-design figures from the report
- Performance figures taken from the report: STT 90%, sound detection 97%, speaker differentiation 55%, typical latency 1–3 seconds (speaker differentiation 3–5 seconds)

## Important before publishing

This website and its repository will be **public**. Review the report and poster for names, student IDs, personal contact details, or any information you don't want publicly accessible. Remove or redact those items before publishing. The performance figures are project-reported, not independently verified. Check that you have the right to publish the included materials.

No backend or personal data collection is used on the website.
